# Replyhand

The `replyhand` MCP server (https://replyhand.com/mcp) works on the person's own Replyhand workspace: their customer conversations, contacts, sales pipeline, product catalog, reports and the setup of the AI agent that answers their customers.

- If the server says it needs authentication, ask the person to run `/mcp auth replyhand` and sign in with their Replyhand account in the browser. There is no API key.
- One connection reaches one workspace, and the person's role decides which tools you see.
- The full connect guide for AI assistants: https://replyhand.com/mcp.md
